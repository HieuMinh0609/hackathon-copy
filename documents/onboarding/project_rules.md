# Rule dự án

1. Mọi thay đổi code phải qua Pull Request và có ít nhất 1 reviewer.
2. Tên branch: `feature/<ten-task>`, `fix/<ten-bug>`.
3. Commit theo chuẩn Conventional Commits (`feat:`, `fix:`, `docs:`).
4. Không commit secret, file `.env`, dữ liệu khách hàng.
5. Không chạy script lạ trên máy chủ chung khi chưa hỏi Tech Lead.
6. Cập nhật trạng thái task hằng ngày trước 10:00.

(Dữ liệu mẫu.)
