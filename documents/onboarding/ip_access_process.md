# Quy trình xin cấp quyền IP

1. Lấy IP máy của bạn: nhờ AI Buddy hoặc chạy `ipconfig`.
2. Tạo ticket loại **Access Request** trên hệ thống IT nội bộ, ghi rõ: IP nguồn, host/port đích, lý do, thời hạn.
3. Tech Lead phê duyệt (SLA 1 ngày làm việc).
4. Đội IT/Network mở rule firewall và phản hồi qua ticket.
5. Kiểm tra lại bằng AI Buddy: `kiểm tra <host>:<port>`.

Lưu ý: nếu truy cập từ xa cần bật VPN công ty trước.

(Dữ liệu mẫu.)
